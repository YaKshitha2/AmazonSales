Amazon Sales Performance Analysis

📌 Project Overview

This project analyzes Amazon sales data to understand sales performance, order trends, product and category performance, and overall business insights.

The project includes data cleaning, data analysis, Pivot Tables, and dashboard creation using Microsoft Excel.

🎯 Objectives

- Analyze overall sales performance
- Identify top-performing categories and products
- Analyze total orders and sales trends
- Understand order status and delivery performance
- Identify key business insights from the sales data

🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Cleaning
- Data Analysis

📊 Project Workflow

1. Imported the Amazon sales dataset
2. Cleaned and prepared the data
3. Performed data analysis using Excel
4. Created Pivot Tables for different business questions
5. Created charts and dashboard
6. Identified key findings and business insights

📈 Analysis Performed

- Total Sales Analysis
- Total Orders Analysis
- Sales by Category
- Sales by Product
- Order Status Analysis
- Sales Trends
- Category-wise Performance
- Overall Business Performance

🔍 Key Findings

- Identified the categories contributing the highest sales.
- Analyzed order volume and overall sales performance.
- Studied order status to understand delivery and order patterns.
- Generated business insights to support better decision-making.

📁 Project Files

- Amazon Sales Dataset
- Cleaned Dataset
- Pivot Tables
- Excel Dashboard
- Project Analysis/Documentation

💡 Conclusion

The Amazon Sales Performance Analysis project demonstrates how Excel can be used for data cleaning, analysis, visualization, and generating meaningful business insights from sales data.
